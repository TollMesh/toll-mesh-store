TollMeshCache

Distributed rate limiting, replay protection, and caching for production systems. Zero-config peer-to-peer coordination using CRDTs.

What is TollMeshCache?

TollMeshCache is a distributed coordination layer built on Conflict-Free Replicated Data Types (CRDTs) that provides three core capabilities:

  • Rate Limiting: Distributed token bucket that works across cluster nodes without a central coordinator
  • Replay Protection: Automatic nonce tracking to prevent duplicate requests/transactions
  • Distributed Caching: TTL-based cache that automatically syncs state across nodes

Unlike Redis or Memcached, TollMeshCache requires no central server, no configuration, and automatically recovers from node failures.

Use Cases

API Rate Limiting

Protect APIs from abuse without running a centralized rate limiting service. Each node can make independent decisions using CRDT consensus.

Example: Limit users to 100 requests/minute across a distributed API cluster. When User A hits their limit on Node 1, they're also rate-limited on Nodes 2-3.

Payment Deduplication

Prevent duplicate charges from retried payment requests. Track transaction IDs globally without requiring synchronous coordination.

Example: User retries payment 3 times in quick succession. First request processes. Retries 2-3 detected as replays and rejected automatically.

Session Caching

Cache session data across multiple servers with automatic TTL expiration and consistency.

Example: User logs in on Server A, data cached. Request routed to Server B - session found in cache. No database calls needed.

Edge Caching

Distribute cache across edge nodes globally. State automatically converges without master-replica complexity.

Example: Cache user preferences at 5 edge locations worldwide. Update in one location, auto-syncs to others.

DDOS Mitigation

Rate limit per IP/region across entire infrastructure instantly.

Example: Suspicious IP makes 1000 requests/sec. Detection on Node 1 instantly affects rate limits on all nodes.

How It Works

CRDT-Based Coordination

TollMeshCache uses Conflict-Free Replicated Data Types (CRDTs) to ensure all nodes converge to the same state without consensus algorithms.

  • GCounter: Grow-only counter for rate limiting (sum of all node counts = current limit)
  • GSet: Grow-only set for replay protection (distributed nonce tracking)
  • ExpiringSet: TTL-based set for caching (auto-cleanup after expiration)

No master election, no consensus required, no configuration needed. Nodes simply exchange state gossip periodically.

Architecture

Component Purpose Scalability
GCounter Distributed rate limiting O(1) per operation, O(n) memory (n=nodes)
GSet Replay protection O(1) per operation, O(m) memory (m=unique nonces)
ExpiringSet TTL caching O(1) per operation, O(k) memory (k=cache keys)
Gossip Protocol State synchronization O(log n) communication cost

Getting Started

Sync client for traditional blocking code:

from tollmeshcache import Client, ClientConfig
from datetime import timedelta

config = ClientConfig(host='localhost', port=8080)
client = Client(config)

# Rate limiting
result = client.consume('user-123', limit=100, window=timedelta(minutes=1))
if not result['ok']:
    raise Exception('Rate limited')

# Replay protection
if client.seen('txn-abc123', ttl=timedelta(hours=24))['seen']:
    raise Exception('Duplicate transaction')

# Caching
client.cache_set('users', 'user-123', user_json, ttl=timedelta(hours=1))
value, exists = client.cache_get('users', 'user-123')

Async Usage

Async client using httpx for high-concurrency scenarios:

import asyncio
from tollmeshcache import AsyncClient, ClientConfig

async def main():
    config = ClientConfig(host='localhost', port=8080)
    async with AsyncClient(config) as client:
        # All methods are async
        result = await client.consume('user-123', 100, timedelta(minutes=1))
        seen = await client.seen('txn-abc123', timedelta(hours=24))
        await client.cache_set('users', 'user-123', user_json, timedelta(hours=1))

asyncio.run(main())

Payment Idempotency

import uuid
from datetime import timedelta

def charge_card(user_id, amount, idempotency_key=None):
    if not idempotency_key:
        idempotency_key = str(uuid.uuid4())

    # Check if already processed
    if cache.seen(f'payment:{idempotency_key}', ttl=timedelta(days=1))['seen']:
        return {'error': 'Duplicate payment', 'status': 'already_processed'}

    # Process payment
    result = payment_provider.charge(user_id, amount)

    # Mark as seen for future retries
    return result

Session Caching

import json
from datetime import timedelta

def get_session(session_id):
    # Try cache first
    cached, exists = cache.cache_get('sessions', session_id)
    if exists:
        return json.loads(cached)

    # Cache miss - fetch from DB
    session = db.sessions.find_one({'_id': session_id})

    # Store in distributed cache
    cache.cache_set('sessions', session_id, json.dumps(session), ttl=timedelta(hours=1))

    return session

Error Handling

from tollmeshcache import TollMeshError, RateLimitError, ReplayError

try:
    result = cache.consume('key', 100, timedelta(minutes=1))
except RateLimitError as e:
    # Handle rate limit specifically
    print(f'Rate limited: {e.message}')
except ReplayError as e:
    # Handle replay detection
    print(f'Replay detected: {e.message}')
except TollMeshError as e:
    # Handle other errors
    print(f'Error {e.code}: {e.message}')

Express.js Middleware

import express from 'express';
import { Client } from 'tollmeshcache';

const app = express();
const cache = new Client();

// Rate limiting middleware
app.use(async (req, res, next) => {
  const userId = req.query.user_id || req.ip;
  const result = await cache.consume(`api:${userId}`, 1000, 60000);

  if (!result.ok) {
    return res.status(429).json({ error: 'Rate limited' });
  }

  res.set('X-RateLimit-Remaining', result.remaining);
  next();
});

app.get('/api/data', (req, res) => {

});

Streaming Support

For large cache values, use streaming to avoid memory issues:

import { streamToBuffer, bufferToStream } from 'tollmeshcache';
import fs from 'fs';

// Stream file into cache
const fileStream = fs.createReadStream('large-file.bin');
const buffer = await streamToBuffer(fileStream);
await client.cacheSet('files', 'large-file', buffer, 3600000);

// Stream from cache to file
const cached = await client.cacheGet('files', 'large-file');
const outStream = bufferToStream(cached[0]);
outStream.pipe(fs.createWriteStream('output.bin'));

Spring Boot Integration

@Component
public class RateLimitInterceptor extends HandlerInterceptorAdapter {
    @Autowired private Client cache;

    @Override
    public boolean preHandle(HttpServletRequest request,
                            HttpServletResponse response,
                            Object handler) throws Exception {
        String userId = request.getParameter("user_id");
        ConsumeResult result = cache.consume(userId, 1000, Duration.ofMinutes(1));

        if (!result.ok) {
            response.setStatus(429);
            response.getWriter().write("Rate limited");
            return false;
        }
        return true;
    }

ASP.NET Core Middleware

public class RateLimitMiddleware
{
    private readonly RequestDelegate _next;
    private readonly Client _client;

    public RateLimitMiddleware(RequestDelegate next)
    {
        _next = next;
        _client = new Client();
    }

    public async Task InvokeAsync(HttpContext context)
    {
        var userId = context.User?.FindFirst(ClaimTypes.NameIdentifier)?.Value;
        var result = await _client.ConsumeAsync(userId, 1000, TimeSpan.FromMinutes(1));

        if (!result.Ok)
        {
            context.Response.StatusCode = 429;
            await context.Response.WriteAsync("Rate limited");
            return;
        }

        await _next(context);
    }
}

API Reference

Core Operations

consume(key, limit, window)

Distributed rate limiting using token bucket algorithm.

Parameter Type Description
key string Rate limit bucket identifier (e.g., user-id, api-key)
limit integer Maximum tokens available in the window
window duration Time window for the limit (milliseconds or duration object)

seen(key, ttl)

Replay protection - check if nonce was already seen.

cache_set(namespace, key, value, ttl)

Store value in distributed cache with TTL.

cache_get(namespace, key)

Retrieve value from distributed cache.
