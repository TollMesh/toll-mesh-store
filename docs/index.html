Architecture

Built on CRDTs (Conflict-Free Replicated Data Types) for automatic state convergence without consensus:

  • GCounter: Grow-only counter (rate limiting)
  • GSet: Grow-only set (replay protection)
  • ExpiringSet: TTL-based set (caching)
  • Gossip Protocol: P2P state synchronization
  • Failure Detection: Automatic node failure handling

Rate Limiting

Distributed token bucket algorithm working peer-to-peer without central coordinator.

Use Cases

API Rate Limiting

Protect APIs from abuse. Each node independently enforces limits using CRDT consensus.

DDOS Protection

Per-IP rate limiting across entire cluster. Detection on one node affects all.

Caching

Distributed TTL-based caching with automatic session management.

Use Cases

Session Storage

Store user sessions across multiple servers with automatic expiration.

Query Result Caching

Cache database query results to reduce database load.

User Data Cache

Cache user profiles, settings, preferences with TTL.

Examples

import json
from datetime import timedelta

def get_user(user_id):
    # Try cache first
    cached, exists = client.cache_get('users', user_id)
    if exists:
        return json.loads(cached)

    # Cache miss - fetch from database
    user = db.query(f"SELECT * FROM users WHERE id = {user_id}")

    # Store in cache for 1 hour
    client.cache_set(
        'users',
        user_id,
        json.dumps(user),
        ttl=timedelta(hours=1)
    )

    return user
async function getUser(userId) {
    // Try cache first
    const [cached, exists] = await client.cacheGet('users', userId);
    if (exists) {
        return JSON.parse(cached.toString());
    }

    // Cache miss - fetch from database
    const user = await db.query(`SELECT * FROM users WHERE id = ${userId}`);

    // Store in cache for 1 hour
    await client.cacheSet(
        'users',
        userId,
        JSON.stringify(user),
        3600000
    );

    return user;
}
public User getUser(String userId) {
    // Try cache first
    CacheValue cached = client.cacheGet("users", userId);
    if (cached.exists) {
        return parseJson(cached.value, User.class);
    }

    // Cache miss - fetch from database
    User user = db.query("SELECT * FROM users WHERE id = ?", userId);

    // Store in cache for 1 hour
    client.cacheSet(
        "users",
        userId,
        toJson(user),
        Duration.ofHours(1)
    );

    return user;
}
async fn get_user(user_id: &str) -> Result {
    // Try cache first
    let (cached, exists) = client.cache_get("users", user_id).await?;
    if exists {
        return Ok(serde_json::from_slice(&cached)?);
    }

    // Cache miss - fetch from database
    let user = db.query_user(user_id).await?;

    // Store in cache for 1 hour
    client.cache_set(
        "users",
        user_id,
        serde_json::to_vec(&user)?,
        Duration::from_secs(3600)
    ).await?;

    Ok(user)
}

public async Task GetUser(string userId) {
    // Try cache first
    var cached = await client.CacheGetAsync("users", userId);
    if (cached.Exists) {
        return JsonConvert.DeserializeObject(cached.Value.ToString());

Pub/Sub Messaging

Pattern-based message broadcasting with history and dead-letter queue.

Features

  • Pattern matching (regex support)
  • Message history
  • Dead-letter queue for failed deliveries
  • Multiple subscribers per topic
  • Real-time notifications

Examples

# Publisher
client.publish('order.created', {'order_id': 123, 'total': 99.99})

# Subscriber
def on_message(message):
    print(f"Order created: {message['payload']}")

# Subscribe to pattern
client.subscribe('order.*', on_message)
// Publisher
await client.publish('order.created',
    JSON.stringify({ order_id: 123, total: 99.99 })
);

// Subscriber
client.subscribe('order.*', (message) => {
    console.log('Order created:', message.payload);
});
// Publisher
client.publish("order.created",
    "{\"order_id\": 123, \"total\": 99.99}"
);

// Subscriber
client.subscribe("order.*", message -> {
    System.out.println("Order created: " + message.payload);
});
// Publisher
client.publish("order.created",
    r#"{"order_id": 123, "total": 99.99}"#
).await?;

// Subscriber
client.subscribe("order.*", |message| {
    println!("Order created: {}", message.payload);
}).await?;
# Publisher
client.publish('order.created',
    {order_id: 123, total: 99.99}.to_json
)

# Subscriber
client.subscribe('order.*') do |message|
  puts "Order created: #{message[:payload]}"
end
// Publisher
await client.PublishAsync("order.created",
    JsonConvert.SerializeObject(new { order_id = 123, total = 99.99 })
);

// Subscriber
client.Subscribe("order.*", (message) => {
    Console.WriteLine($"Order created: {message.Payload}");
});
// Publisher
$client->publish('order.created',
    json_encode(['order_id' => 123, 'total' => 99.99])
);

// Subscriber
$client->subscribe('order.*', function($message) {
    echo "Order created: " . $message['payload'];
});

Lua Scripting

Custom script execution for complex operations.

Example

-- Register script
script = '''
if cache_get(KEYS[1]) then
    return 'exists'
else
    cache_set(KEYS[1], ARGV[1], ARGV[2])
    return 'set'
end
'''

script_id = client.register_script(script)

# Execute script
result = client.eval_script(script_id, ['user-123'], ['data', '3600'])

API Reference

Core Operations

Operation Description Returns
consume(key, limit, window) Rate limiting {ok, remaining, reset_at}
seen(key, ttl) Replay protection {seen}
cache_get(ns, key) Get cached value {value, exists}
cache_set(ns, key, value, ttl) Set cached value {ok}
publish(topic, message) Publish message {subscribers_count}
subscribe(topic, callback) Subscribe to topic subscription_id
