Core Operations

Essential functions for rate limiting, replay protection, and caching.

Consume - Rate Limiting

meshStore.Consume(ctx, key, limit, window)
Check if a request is within rate limits. Consumes tokens from a bucket and returns whether the request is allowed. Perfect for API rate limiting, preventing abuse, and protecting services from overload. Returns remaining tokens and reset time for client-side handling.
Parameters:
• ctx: Context for cancellation
• key: Unique identifier (e.g., "user:123", "api:endpoint")
• limit: Maximum requests allowed
• window: Time window (e.g., 60*time.Second for 1 minute)
Returns: {ok: bool, remaining: int, resetAt: int64}
Go Example: result, err := meshStore.Consume(ctx, "api:user:123", 100, 60*time.Second) if err != nil { return err } if !result.OK { return fmt.Errorf("rate limited, reset at %d", result.ResetAt) } // Process request

Seen - Replay Protection

meshStore.Seen(ctx, key, nonce)
Detect and prevent replay attacks by tracking seen nonces. Checks if a request nonce was previously seen. Essential for security in distributed systems to prevent duplicate request processing. Automatically stores the nonce for future comparisons.
Parameters:
• ctx: Context for cancellation
• key: Request identifier (e.g., "request:123")
• nonce: Unique request identifier
Returns: {seen: bool, stored: bool}
Go Example: result, err := meshStore.Seen(ctx, "request:nonce", requestNonce) if err != nil { return err } if result.Seen { return fmt.Errorf("replay attack detected") } // Process request

Get - Retrieve Cached Value

meshStore.Get(ctx, key)
Retrieve a cached value by key. Returns the value if it exists and hasn't expired. Fast O(1) operation perfect for caching frequently accessed data. Returns nil if key doesn't exist or has expired.
Parameters:
• ctx: Context for cancellation
• key: Cache key to retrieve
Returns: {value: interface{}, ttl: int64, error}
Go Example: value, ttl, err := meshStore.Get(ctx, "user:profile:123") if err != nil { return err } if value != nil { return value // Cache hit } // Cache miss, fetch from database

Set - Store Cached Value

meshStore.Set(ctx, key, value, ttl)
Store a value in cache with optional TTL (Time To Live). Automatically expires after TTL. Perfect for caching database results, API responses, and computed values. Supports any serializable value type.
Parameters:
• ctx: Context for cancellation
• key: Cache key
• value: Value to cache
• ttl: Time to live (0 = no expiration)
Returns: error
Go Example: profile := fetchFromDatabase("user:123") err := meshStore.Set(ctx, "user:profile:123", profile, 3600*time.Second) if err != nil { return err } // Value cached for 1 hour

Delete - Remove Cached Value

meshStore.Delete(ctx, key)
Remove a value from cache immediately. Useful for cache invalidation when data changes. Fast O(1) operation that removes the key and all associated data. Safe to call even if key doesn't exist.
Parameters:
• ctx: Context for cancellation
• key: Cache key to delete
Returns: error
Go Example: err := meshStore.Delete(ctx, "user:profile:123") if err != nil { return err } // Value removed from cache

Coordination Functions

Manage distributed cluster coordination, peer discovery, and state synchronization.

Peer Management

peerManager.AddPeer(peer)
Add a new peer to the cluster for distributed coordination. Enables peer-to-peer communication. Automatically starts health monitoring and state synchronization with the new peer. Returns error if peer already exists.
Parameters:
• peer.ID: Unique peer identifier
• peer.Address: IP address or hostname
• peer.Port: Port number
Returns: error
Go Example: err := peerManager.AddPeer(&Peer{ ID: "node2", Address: "192.168.1.2", Port: 8000, }) if err != nil { return err }
peerManager.RemovePeer(peerID)
Remove a peer from the cluster. Stops communication and monitoring with that peer. Useful when decommissioning nodes or handling node failures. Automatically redistributes data to remaining peers.
Parameters:
• peerID: ID of the peer to remove
Returns: error
Go Example: err := peerManager.RemovePeer("node2") if err != nil { return err } // Peer removed from cluster

State Synchronization

stateSync.SyncState(state)
Synchronize state with other peers using Merkle trees for efficiency. Detects differences. Only transfers changed data, minimizing network overhead. Ensures eventual consistency across all nodes.
Parameters:
• state: Current MeshStoreState to sync
Returns: error
Go Example: err := stateSync.SyncState(currentState) if err != nil { return err } // State synchronized with peers

Failure Detection

failureDetector.MarkSuspect(peerID)
Mark a peer as suspected failed for monitoring. Uses suspicion-based detection. Automatically attempts recovery and notifies other peers. Prevents false positives from temporary network issues.
Parameters:
• peerID: ID of the peer to mark
Returns: error
Go Example: err := failureDetector.MarkSuspect("node2") if err != nil { return err } // Peer marked for monitoring

Persistence Functions

Manage durable storage with Write-Ahead Log, snapshots, and crash recovery.

Write-Ahead Log (WAL)

wal.Write(entry)
Write an operation entry to the Write-Ahead Log for durability. Ensures no data loss. Entries are persisted before being applied to the state. Supports automatic segment rotation for efficient storage.
Parameters:
• entry.Op: Operation type (SET, DELETE, etc.)
• entry.Key: Data key
• entry.Value: Data value
Returns: error
Go Example: err := wal.Write(&Entry{ Op: "SET", Key: "user:123", Value: userData, }) if err != nil { return err }
wal.Read(fromTimestamp)
Read WAL entries from a specific timestamp onwards. Used for recovery and replication. Returns all entries that occurred after the given timestamp. Efficient for catching up after node restart.
Parameters:
• fromTimestamp: Start reading from this timestamp
Returns: []*Entry, error
Go Example: entries, err := wal.Read(time.Now().UnixMilli() - 3600000) if err != nil { return err } // Process entries from last hour

Snapshots

snapshotManager.CreateSnapshot(snapshot)
Create a point-in-time snapshot of the entire state. Enables fast recovery. Automatically manages snapshot retention and cleanup. Snapshots are compressed and stored efficiently.
Parameters:
• snapshot: Complete state to snapshot
Returns: error
Go Example: err := snapshotManager.CreateSnapshot(&Snapshot{ RateLimiters: data, Timestamp: time.Now().UnixMilli(), }) if err != nil { return err }
snapshotManager.GetLatestSnapshot()
Retrieve the most recent snapshot for recovery. Used during node startup. Returns the latest complete state snapshot available. Enables fast recovery without replaying entire WAL.
Returns: *Snapshot, error
Go Example: snapshot, err := snapshotManager.GetLatestSnapshot() if err != nil { return err } // Use snapshot for recovery

Recovery

recoveryManager.RecoverFromCrash()
Recover from crash using snapshots or WAL replay. Automatic recovery process. Tries snapshot first for speed, falls back to WAL replay if needed. Ensures data consistency after unexpected shutdown.
Returns: error
Go Example: err := recoveryManager.RecoverFromCrash() if err != nil { return err } // System recovered and ready

Advanced Features

Sharding, replication, and load balancing for horizontal scaling.

Consistent Hashing (Sharding)

ring.AddNode(node)
Add a node to the consistent hash ring for data sharding. Enables horizontal scaling. Uses virtual nodes for even data distribution across cluster. Automatically rebalances data when nodes are added.
Parameters:
• node.ID: Unique node identifier
• node.Address: Node address
• node.Port: Node port
Returns: error
Go Example: err := ring.AddNode(&Node{ ID: "node1", Address: "localhost", Port: 8000, }) if err != nil { return err }
ring.GetNode(key)
Get the node responsible for a key in the hash ring. Determines data location. Uses consistent hashing to ensure same key always maps to same node. O(log n) operation for efficient lookup.
Parameters:
• key: Data key to locate
Returns: *Node, error
Go Example: node, err := ring.GetNode("user:123") if err != nil { return err } // Send request to responsible node

Replication

replicationManager.ReplicateKey(key, value)
Replicate a key to multiple nodes for fault tolerance. Configurable replication factor. Automatically maintains replicas across different nodes. Enables data recovery if primary node fails.
Parameters:
• key: Key to replicate
• value: Value to replicate
Returns: error
Go Example: err := replicationManager.ReplicateKey("user:123", userData) if err != nil { return err } // Data replicated to multiple nodes
replicationManager.PerformReadRepair(key)
Perform read repair to fix inconsistent replicas. Ensures consistency. Detects and fixes diverged replicas during read operations. Automatic healing without manual intervention.
Parameters:
• key: Key to repair
Returns: error
Go Example: err := replicationManager.PerformReadRepair("user:123") if err != nil { return err } // Replicas repaired

Load Balancing

loadBalancer.SelectNode()
Select a node based on load balancing strategy. Distributes requests evenly. Supports multiple strategies: round-robin, least-connections, health-aware. Automatically skips unhealthy nodes.
Returns: *Node, error
Go Example: node, err := loadBalancer.SelectNode() if err != nil { return err } // Send request to selected node
loadBalancer.MarkNodeHealthy(nodeID)
Mark a node as healthy for load balancing. Re-enables request routing. Called after node recovery or health check success. Automatically includes node in load balancing decisions.
Parameters:
• nodeID: ID of the node
Returns: error
Go Example: err := loadBalancer.MarkNodeHealthy("node1") if err != nil { return err } // Node marked healthy

Health Check Functions

Monitor system health and readiness for production deployments.

GET /health/live
Liveness probe - checks if the service is running. Used by orchestrators like Kubernetes. Returns immediately if service is alive, fails if service is down. Should be called frequently (every 10-30 seconds).
Response: { "status": "alive" }
Example: curl http://localhost:8080/health/live
GET /health/ready
Readiness probe - checks if service is ready to serve requests. More comprehensive than liveness. Checks all dependencies: database, cache, peers, etc. Returns detailed component status for debugging.
Response: { "status": "ready", "components": {...} }
Example: curl http://localhost:8080/health/ready

Real-World Examples

Example 1: API Rate Limiting

// Protect API endpoint with rate limiting func handleRequest(w http.ResponseWriter, r *http.Request) { userID := r.Header.Get("X-User-ID") // Check rate limit: 100 requests per minute result, err := meshStore.Consume(r.Context(), fmt.Sprintf("api:user:%s", userID), 100, 60*time.Second) if err != nil { http.Error(w, "Service error", http.StatusInternalServerError) return } if !result.OK { w.Header().Set("Retry-After", fmt.Sprintf("%d", result.ResetAt)) http.Error(w, "Rate limit exceeded", http.StatusTooManyRequests) return } // Process request w.WriteHeader(http.StatusOK) w.Write([]byte("Request processed")) }

Example 2: Replay Attack Prevention

// Prevent replay attacks on sensitive operations func handlePayment(w http.ResponseWriter, r *http.Request) { requestID := r.Header.Get("X-Request-ID") // Check if this request was already processed result, err := meshStore.Seen(r.Context(), "payment:request", requestID) if err != nil { http.Error(w, "Service error", http.StatusInternalServerError) return } if result.Seen { // Request already processed, return cached response http.Error(w, "Duplicate request", http.StatusConflict) return } // Process payment processPayment() w.WriteHeader(http.StatusOK) }

Example 3: Distributed Caching

// Cache user profile with 1 hour TTL func getUserProfile(userID string) (*Profile, error) { ctx := context.Background() // Try cache first cached, _, err := meshStore.Get(ctx, fmt.Sprintf("profile:%s", userID)) if err == nil && cached != nil { return cached.(*Profile), nil } // Cache miss, fetch from database profile := fetchFromDatabase(userID) // Store in cache for 1 hour err = meshStore.Set(ctx, fmt.Sprintf("profile:%s", userID), profile, 3600*time.Second) return profile, err }
