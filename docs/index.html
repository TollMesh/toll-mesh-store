Phase 1: Gossip Protocol

Distributed peer-to-peer state synchronization with automatic failure detection and recovery.

Core Functions

PeerManager.AddPeer(peer *Peer) error
Add a new peer to the cluster
Parameters:
peer: Peer object with ID, Address, Port
Returns: error if peer already exists
Example:
pm.AddPeer(&Peer{ID: "node2", Address: "192.168.1.2", Port: 8000})
PeerManager.RemovePeer(peerID string) error
Remove a peer from the cluster
Parameters:
peerID: ID of the peer to remove
Returns: error if peer not found
Example:
pm.RemovePeer("node2")
StateSync.SyncState(state *MeshStoreState) error
Synchronize state with other peers using Merkle trees
Parameters:
state: Current state to sync
Returns: error if sync fails
Example:
ss.SyncState(currentState)
FailureDetector.MarkSuspect(peerID string) error
Mark a peer as suspected failed
Parameters:
peerID: ID of the peer
Returns: error if peer not found
Example:
fd.MarkSuspect("node2")

Phase 2: HTTP API

REST API endpoints for rate limiting, replay protection, caching, and health checks.

Core Functions

POST /consume
Rate limit check - consume tokens from a bucket
Request Body:
{ "key": "user:123", "limit": 100, "window": 60000 }
Response: { "ok": true, "remaining": 99, "reset_at": 1234567890 }
Example:
curl -X POST http://localhost:8080/consume -d '{"key":"user:123","limit":100,"window":60000}'
POST /seen
Replay protection - check if nonce was seen before
Request Body:
{ "key": "request:123", "nonce": "abc123" }
Response: { "seen": false, "stored": true }
Example:
curl -X POST http://localhost:8080/seen -d '{"key":"request:123","nonce":"abc123"}'
GET /get/:key
Get cached value
Parameters:
key: Cache key
Response: { "value": "cached_value", "ttl": 3600 }
Example:
curl http://localhost:8080/get/mykey
POST /set
Set cached value with TTL
Request Body:
{ "key": "mykey", "value": "myvalue", "ttl": 3600 }
Response: { "ok": true }
Example:
curl -X POST http://localhost:8080/set -d '{"key":"mykey","value":"myvalue","ttl":3600}'
GET /health/live
Liveness probe - is the service running?
Response: { "status": "alive" }
Example:
curl http://localhost:8080/health/live
GET /health/ready
Readiness probe - is the service ready to serve?
Response: { "status": "ready", "components": {...} }
Example:
curl http://localhost:8080/health/ready

Phase 3: Persistence

Durable storage with Write-Ahead Log, snapshots, and crash recovery.

Core Functions

WriteAheadLog.Write(entry *Entry) error
Write an entry to the WAL
Parameters:
entry: Entry with operation data
Returns: error if write fails
Example:
wal.Write(&Entry{Op: "SET", Key: "k1", Value: "v1"})
WriteAheadLog.Read(fromTimestamp int64) ([]*Entry, error)
Read entries from WAL starting from timestamp
Parameters:
fromTimestamp: Start reading from this timestamp
Returns: slice of entries and error
Example:
entries, err := wal.Read(time.Now().UnixMilli() - 3600000)
SnapshotManager.CreateSnapshot(snapshot *Snapshot) error
Create a point-in-time snapshot
Parameters:
snapshot: Snapshot data
Returns: error if creation fails
Example:
sm.CreateSnapshot(&Snapshot{RateLimiters: data})
SnapshotManager.GetLatestSnapshot() (*Snapshot, error)
Get the most recent snapshot
Returns: Latest snapshot and error
Example:
snapshot, err := sm.GetLatestSnapshot()
RecoveryManager.RecoverFromCrash() error
Recover from crash using snapshots or WAL replay
Returns: error if recovery fails
Example:
err := rm.RecoverFromCrash()

Phase 4: Advanced Features

Sharding, replication, and load balancing for horizontal scaling.

Core Functions

Ring.AddNode(node *Node) error

Parameters:
node: Node to add
Returns: error if add fails
Example:
ring.AddNode(&Node{ID: "node1", Address: "localhost", Port: 8000})
Ring.GetNode(key string) (*Node, error)
Get the node responsible for a key
Parameters:
key: Cache key
Returns: Responsible node and error
Example:
node, err := ring.GetNode("user:123")

Replicate a key to multiple nodes
Parameters:
key: Key to replicate
value: Value to replicate
Returns: error if replication fails
Example:

Select a node based on load balancing strategy
Returns: Selected node and error

LoadBalancer.MarkNodeHealthy(nodeID string) error
Mark a node as healthy
Parameters:
nodeID: ID of the node
Returns: error if node not found
Example:
lb.MarkNodeHealthy("node1")

Real-World Examples

Example 1: API Rate Limiting

// Check if user exceeded rate limit result, err := meshStore.Consume(ctx, "api:user:123", 1000, 3600*time.Second) if err != nil { return err } if !result.OK { return fmt.Errorf("rate limit exceeded, reset at %d", result.ResetAt) } // Process request processRequest()

Example 2: Replay Attack Prevention

// Check if request nonce was seen before result, err := meshStore.Seen(ctx, "request:nonce", requestNonce) if err != nil { return err } if result.Seen { return fmt.Errorf("replay attack detected") } // Process request processRequest()

Example 3: Distributed Caching

// Try to get from cache cached, err := meshStore.Get(ctx, "user:profile:123") if err == nil && cached != nil { return cached } // Cache miss, fetch from database profile := fetchFromDatabase("user:123") // Store in cache with 1 hour TTL meshStore.Set(ctx, "user:profile:123", profile, 3600*time.Second) return profile

Example 4: Cluster Setup

// Create cluster with 3 nodes nodes := []*Node{ {ID: "node1", Address: "192.168.1.1", Port: 8000}, {ID: "node2", Address: "192.168.1.2", Port: 8000}, {ID: "node3", Address: "192.168.1.3", Port: 8000}, } // Add nodes to ring ring := NewRing(ShardingConfig{ VirtualNodes: 150, ReplicationFactor: 3, }) for _, node := range nodes { ring.AddNode(node) } // Get responsible node for key node, err := ring.GetNode("user:123")
