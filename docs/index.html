Powerful Features

🔄 Distributed by Default

No complex setup required. TollMeshStore is built for distributed systems from the ground up with automatic peer discovery and state synchronization.

💾 Durable Storage

Write-Ahead Log ensures no data loss. Automatic snapshots enable fast recovery. Your data is safe even after crashes.

🚀 Horizontal Scaling

Add nodes on the fly. Automatic sharding and replication distribute data evenly. Scale from 1 to 1000+ nodes.

⚡ Lightning Fast

Sub-millisecond latency for local operations. Optimized for high throughput. Handles millions of operations per second.

Health checks, metrics, and monitoring. Kubernetes-ready with liveness and readiness probes. Enterprise-grade reliability.

Get Started in Minutes

Installation

Install TollMeshStore using your favorite package manager:

go get github.com/TollMesh/toll-mesh-store

Or use Docker:

docker run -p 8080:8080 tollmesh/toll-mesh-store

Basic Usage

Start using TollMeshStore in your application:

// Rate limiting result, err := meshStore.Consume(ctx, "user:123", 100, 60*time.Second) if !result.OK { return fmt.Errorf("rate limited") } // Caching meshStore.Set(ctx, "key", "value", 3600*time.Second) value, _, _ := meshStore.Get(ctx, "key")
